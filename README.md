# 📁 Project


## Medical Device Failure Analysis

**Tools:** Power BI

Analyzed medical device data to identify **failure patterns and device performance trends**. The project focused on understanding which devices require higher maintenance and identifying patterns that could support better maintenance planning.

### 🔍 Key Analysis

* Analyzed device failure patterns
* Evaluated maintenance classifications
* Identified devices with higher maintenance requirements
* Analyzed failure and maintenance trends over time
* Compared device performance across different categories
* Analyzed monthly and yearly trends
* Developed KPIs to monitor device performance
* Created interactive Power BI dashboards to present findings
